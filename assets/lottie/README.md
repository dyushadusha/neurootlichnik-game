# Lottie-анимации «Нейро Отличник»

Набор из 10 анимаций для Telegram-канала: 2 анимированных логотипа и
8 анимированных реакций. Все — в фирменных цветах бренда:

- лайм `#dbfc3b` — акцент/заливка
- графит `#2a2a2a` — обводки и тёмные акценты
- прозрачный фон — вставляются куда угодно (пост, реакция, стикер, кружок)

Только векторные фигуры (без картинок и шрифтов) — совместимо с
требованиями Telegram к анимированным стикерам/эмодзи (`.tgs`).

## Как использовать в Telegram

**Как обычную Lottie-анимацию** (в ботах, веб-виджетах, на сайте) —
файлы уже готовы, просто отдайте `.json` любому Lottie-плееру
(`lottie-web`, `lottie-react` и т.п.).

**Как анимационный стикер/кастомный эмодзи Telegram (`.tgs`)** — Telegram
требует gzip-сжатый Lottie JSON с расширением `.tgs`, канвас 512×512,
до 3 секунд и до 60 кадров/сек (это всё уже соблюдено для реакций и
`logo-icon-loop.json`; `logo-wordmark-reveal.json` — широкий формат,
используйте его как обычный Lottie/видео, а не как стикер 512×512).

Конвертация в `.tgs` (два варианта):

1. Через Telegram-бота [@Stickers](https://t.me/Stickers) — команда
   «Add a new sticker pack» → «animated sticker» → прикрепить `.json`
   (бот сам переименует/упакует в `.tgs`).
2. Локально через утилиту [`lottie`](https://pypi.org/project/lottie/):
   ```bash
   pip install "lottie[all]"
   lottie_convert.py assets/lottie/reaction-heart.json reaction-heart.tgs
   ```

## Как пересобрать / изменить

Все анимации генерируются кодом из `tools/lottie/` — ничего не
редактируется в JSON руками.

```bash
npm run generate-lottie   # пересобрать все 10 файлов в assets/lottie/
node tools/lottie/validate.js  # структурная проверка JSON
```

- `tools/lottie/lib.js` — общая библиотека: парсер SVG `path d` → Lottie
  bezier, билдеры фигур/заливки/обводки/трансформаций/кейфреймов.
- `tools/lottie/build-logos.js` — логотипы (используют реальные контуры
  из `assets/logo-icon.svg` и `assets/logo-full.svg`).
- `tools/lottie/build-reactions.js` — 8 реакций.

Чтобы поменять акцентный цвет всего набора — поменяйте `BRAND.lime` /
`BRAND.ink` в `tools/lottie/lib.js` и перезапустите `npm run
generate-lottie`.
