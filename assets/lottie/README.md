# Lottie-анимации «Нейро Отличник»

50 анимаций для Telegram-канала: **12 логотипов**, **18 реакций на пост**
и **20 кастомных эмодзи**. Все — в фирменных цветах студии:

- лайм `#dbfc3b` — заливка
- графит `#2a2a2a` — обводки и тёмные детали
- белый — блики (по одному на иконку, одинаковым приёмом на весь набор)
- прозрачный фон — вставляются куда угодно
- фирменная смещённая тень (тот же приём, что `--doodle-shadow` в `src/style.css`)

Только векторные фигуры — без растра и шрифтов, поэтому пак совместим
с форматом Telegram `.tgs`.

## Единая система иконок

50 файлов держатся вместе не только движением, но и правилами рисунка
(`tools/lottie/icons.js`):

| Правило | Зачем |
|---|---|
| **Общий бокс 200×200** | вся геометрия в одной системе координат, дальше масштабируется под 512 или 100 |
| **Оптический вес (`fit`)** | габарит и видимая масса — разное: круг при равном размере крупнее квадрата, а звезда легче обоих, поэтому у каждой иконки своя поправка |
| **Обводка снаружи** | заливка кладётся поверх обводки, иначе внутренняя половина штриха съедает лайм — от этого молния, ручки кубка и лучи звезды выглядели тонкими |
| **Белый блик** | одна и та же капсула в верхней части каждой иконки: связывает набор и добавляет объёма |

## Как устроено движение

Набор держится на одном «языке движения» — поэтому 50 файлов читаются
как единый пак, а не как случайная подборка:

| Приём | Что делает |
|---|---|
| **Пружина с перелётом** | объект проскакивает финальный размер и затухающе возвращается — вместо линейного «доезда» |
| **Squash & stretch** | по X и Y движение идёт с лагом в 3 кадра, объём тянется и сплющивается |
| **Anticipation** | перед броском — короткий замах в обратную сторону |
| **Follow-through** | искры, лучи и детали (кисточка на шапочке) стартуют позже и успокаиваются позже основного объёма |
| **Impact** | в кадре удара вылетают лучи, расходится кольцо |
| **Живой idle** | после посадки объект дышит/качается, а не замирает |

Сложные кривые (пружины, отскоки, затухающие колебания) Lottie не умеет
описывать одним безье — поэтому в `tools/lottie/motion.js` они
**запекаются**: функция сэмплируется по кадрам в плотный набор ключей.

## Логотипы (12) — канвас 512×512, кроме широких

| Файл | Что происходит |
|---|---|
| `logo-icon-wink.json` | знак читается как очки — и подмигивает правой линзой |
| `logo-icon-pop.json` | замах и упругое появление с искрами |
| `logo-icon-bounce.json` | падает сверху, сплющивается на посадке |
| `logo-icon-stamp.json` | впечатывается как штамп, лучи удара |
| `logo-icon-flip.json` | разворот «в профиль» через ноль |
| `logo-icon-swing.json` | висит на невидимой нити и раскачивается маятником |
| `logo-icon-pulse.json` | расходящиеся кольца — «в эфире», для аватара |
| `logo-icon-orbit.json` | искры на орбите, спокойный луп для аватара |
| `logo-icon-glitch.json` | лайм и графит сходятся из глитча в чистый знак |
| `logo-wordmark-wave.json` | 1600×420 — буквы влетают волной |
| `logo-wordmark-wipe.json` | 1600×420 — лаймовая шторка проявляет леттеринг |
| `logo-wordmark-type.json` | 1600×420 — печатная машинка с мигающим курсором |

## Реакции (18) — канвас 512×512

`heart` (сердцебиение) · `fire` (живой фликер) · `thumbsup` · `star` ·
`lightbulb` (лучи волной) · `perfect` (штамп с галочкой) · `confetti` ·
`gradcap` (кисточка качается сама) · `clap` (ладони бьются) · `rocket`
(старт со следом) · `brain` (импульсы по сети) · `eyes` (фирменные очки,
моргают) · `crown` · `bolt` · `trophy` · `hundred` («100» — оценка
отличника) · `gem` (блик по грани) · `wow` (звёздный взрыв)

Файлы: `reaction-<имя>.json`

## Эмодзи (20) — канвас 100×100

Формат кастомных эмодзи Telegram: крупный силуэт и утолщённая обводка,
чтобы читаться в размере строки текста.

`check` · `cross` · `star` · `heart` · `fire` · `spark` · `bolt` ·
`arrow-up` · `arrow-right` · `pin` · `question` · `percent` · `clock` ·
`dots` · `eye` · `cube` · `house` · `camera` · `palette` · `bulb`

Файлы: `emoji-<имя>.json`. Последние пять — про профиль студии:
куб и дом (архитектура), камера (ракурс/рендер), палитра (стиль),
лампочка (идея).

## Как загрузить в Telegram

**Как обычную Lottie** (боты, сайт, виджеты) — файлы готовы, отдайте
`.json` любому Lottie-плееру (`lottie-web`, `lottie-react`).

**Как стикеры и кастомные эмодзи (`.tgs`)** — Telegram требует
gzip-сжатый Lottie: до 3 секунд, 30 или 60 fps, 512×512 для стикеров
и 100×100 для эмодзи, до 64 КБ в упакованном виде. Всё это уже
соблюдено и проверяется на сборке (`node tools/lottie/validate.js`);
самый тяжёлый файл набора — около 12 КБ из 64 допустимых.

1. Через бота [@Stickers](https://t.me/Stickers): `Add a new sticker pack`
   → `animated sticker` → прикрепить `.json` (для эмодзи —
   `Create a new emoji pack`).
2. Локально:
   ```bash
   pip install "lottie[all]"
   lottie_convert.py assets/lottie/reaction-heart.json reaction-heart.tgs
   ```

Три широких файла (`logo-wordmark-wave`, `logo-wordmark-wipe`,
`logo-wordmark-type`) в стикер-пак не идут — у них не квадратный
канвас. Это заставки для видео, сайта и шапок, а не стикеры.

## Как пересобрать или изменить

Ни один JSON не редактируется руками — всё генерируется кодом.

```bash
npm run generate-lottie        # пересобрать все 50 файлов
node tools/lottie/validate.js  # схема + требования Telegram
```

| Файл | Отвечает за |
|---|---|
| `tools/lottie/lib.js` | примитивы Lottie: парсер SVG `path d` → кривые, фигуры, слои, ключи |
| `tools/lottie/motion.js` | язык движения: пружины, отскоки, дыхание, дрожание |
| `tools/lottie/icons.js` | азбука иконок: геометрия, оптический вес, обводка и блики |
| `tools/lottie/compose.js` | сборка стикера: вход, акценты, тень |
| `tools/lottie/build-*.js` | сами наборы: логотипы, реакции, эмодзи |

Поменять акцентный цвет всего пака — одна строка `BRAND.lime`
в `tools/lottie/lib.js`, дальше `npm run generate-lottie`.
