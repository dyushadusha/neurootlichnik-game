# Lottie-анимации «Нейро Отличник»

61 анимация для Telegram-канала: **23 логотипа** (10 коротких — знак,
10 полных — знак + леттеринг, 3 широких видео-леттеринга), **18
реакций на пост** и **20 кастомных эмодзи**. Все — в фирменных цветах
студии:

- лайм `#dbfc3b` — заливка
- графит `#2a2a2a` — обводки и тёмные детали
- белый — блики (по одному на иконку, одинаковым приёмом на весь набор)
- прозрачный фон — вставляются куда угодно
- фирменная смещённая тень (тот же приём, что `--doodle-shadow` в `src/style.css`)

Только векторные фигуры — без растра и шрифтов, поэтому пак совместим
с форматом Telegram `.tgs`.

## Единая система иконок

61 файл держится вместе не только движением, но и правилами рисунка
(`tools/lottie/icons.js`):

| Правило | Зачем |
|---|---|
| **Общий бокс 200×200** | вся геометрия в одной системе координат, дальше масштабируется под 512 или 100 |
| **Оптический вес (`fit`)** | габарит и видимая масса — разное: круг при равном размере крупнее квадрата, а звезда легче обоих, поэтому у каждой иконки своя поправка |
| **Обводка снаружи** | заливка кладётся поверх обводки, иначе внутренняя половина штриха съедает лайм — от этого молния, ручки кубка и лучи звезды выглядели тонкими |
| **Белый блик** | одна и та же капсула в верхней части каждой иконки: связывает набор и добавляет объёма |

## Как устроено движение

Набор держится на одном «языке движения» — поэтому 61 файл читается
как единый пак, а не как случайная подборка:

| Приём | Что делает |
|---|---|
| **Пружина с перелётом** | объект проскакивает финальный размер и затухающе возвращается — вместо линейного «доезда» |
| **Squash & stretch** | по X и Y движение идёт с лагом в 3 кадра, объём тянется и сплющивается |
| **Anticipation** | перед броском — короткий замах в обратную сторону |
| **Follow-through** | искры, лучи и детали (кисточка на шапочке) стартуют позже и успокаиваются позже основного объёма |
| **Impact** | в кадре удара вылетают лучи, расходится кольцо |
| **Живой idle** | после посадки объект дышит/качается, а не замирает |

Сложные кривые (пружины, отскоки, затухающие колебания) Lottie не умеет
описывать одним безье — поэтому в `tools/lottie/motion.js` они
**запекаются**: функция сэмплируется по кадрам в плотный набор ключей.

### Полные — знак + леттеринг «Нейро Отличник» (10)

Знак нарисован широким (2.8:1), строка леттеринга — ещё шире (10.9:1):
друг под другом в квадратном канвасе они всегда оставляют поля
сверху/снизу — это нарочная компоновка лого-блока, а не попытка
растянуть его на весь квадрат (`lockupGeometry()` в
`tools/lottie/build-logos.js` считает эти отступы для каждого файла).

| Файл | Что происходит |
|---|---|
| `logo-full-pop.json` | знак появляется пружиной, следом волной влетают буквы |
| `logo-full-drop.json` | знак падает сверху, строка встаёт снизу — встреча посередине |
| `logo-full-wipe.json` | знак уже на месте, лаймовая шторка проявляет строку |
| `logo-full-type.json` | знак появляется, строка печатается как на машинке |
| `logo-full-stamp.json` | знак и строка впечатываются одним ударом, лучи и тряска |
| `logo-full-swing.json` | вся связка качается вместе, как маятник на одной нити |
| `logo-full-orbit.json` | искры облетают всю связку по орбите — спокойный луп |
| `logo-full-glitch.json` | знак и строка сходятся из глитч-двойников |
| `logo-full-shutter.json` | ламели-жалюзи раскрывают уже готовую связку |
| `logo-full-split.json` | знак и строка съезжаются с разных сторон навстречу друг другу |

## Эмодзи (20) — канвас 512×512

Канвас тот же, что у стикеров: Telegram требует 512×512 для **всех**
анимированных `.tgs`, включая кастомные эмодзи (100×100 — это про
статичные картинки-эмодзи, не про анимацию). Отличается рисунок:
силуэт крупнее, обводка вдвое толще, вход короче — чтобы читаться
в размере строки текста.

`arrow-up` · `arrow-right` · `pin` · `question` · `percent` · `clock` ·
`dots` · `eye` · `cube` · `house` · `camera` · `palette` · `bulb`

## Как загрузить в Telegram

**Как обычную Lottie** (боты, сайт, виджеты) — файлы готовы, отдайте
`.json` любому Lottie-плееру (`lottie-web`, `lottie-react`).

**Как стикеры и кастомные эмодзи (`.tgs`)** — готовые файлы собирает

```bash
npm run make-tgs        # → dist/tgs/stickers/ и dist/tgs/emoji/
```

`.tgs` — это не просто «gzip от Lottie»: Telegram опознаёт формат по
маркеру `"tgs": 1` в корне документа и отклоняет файл, если внутри
есть неподдерживаемые возможности. Полный список запрещённого —
Merge Paths, **Star Shapes**, Gradient Strokes, Repeaters, Time
Stretching/Remapping, Expressions, Images, Texts, Layer Effects,
Masks, Mattes, Auto-Oriented Layers. Плюс лимиты: канвас ровно
512×512, до 3 секунд, 30/60 fps, до 64 КБ в упакованном виде, и
объекты не должны выходить за края канваса.

Скрипт проверяет каждый файл по этому списку и пакует только
прошедшие. Поэтому в наборе нет параметрических звёзд — все звёздчатые
формы считаются по вершинам и отдаются обычными контурами.

### Чем rlottie отличается от веб-плеера

Проигрывает `.tgs` не lottie-web, а **rlottie** — он строже, и на его
правилах легко получить не «кривую анимацию», а полностью пустой
стикер: свойство замирает на первом ключе, а первый ключ у любого
появления — нулевой масштаб. Два правила, которые это вызывают
(валидатор их проверяет):

- **у последнего ключевого кадра не должно быть easing** (`i`/`o`) и
  поля `e` — он терминатор, только время и значение;
- **никаких вырожденных ручек** `x = 0` или `x = 1`. Строго линейная
  интерполяция — это `cubic-bezier(1/3, 1/3, 2/3, 2/3)`, то есть
  `o.x = 0.333`, `i.x = 0.667`.

lottie-web оба нарушения прощает, так что проверка в браузере их не
ловит — только рендер настоящим rlottie.

### Почему у превью в списке пака иконка была не видна

Список стикер-пака и кастомных эмодзи в Telegram — это не отдельная
картинка, а статичный рендер САМОГО РАННЕГО кадра `.tgs`-файла. Весь
набор построен на «появлении из ничего» (пружина от масштаба 0 или от
прозрачности 0), поэтому на нулевом кадре объекта не было видно вообще
ни на одной анимации — сама анимация при этом играла нормально, стоило
открыть пак и подождать. Теперь у входа `pop`/`anticipate`/`flip`
объект на нулевом кадре не отсутствует, а уже виден на ~60% размера
(так превью в списке читается), у `drop`/`stamp` высота
падения/замаха считается по фактическому размеру иконки так, чтобы
объект не пересекал край канваса — прятать его прозрачностью больше
не нужно.

Дальше — бот [@Stickers](https://t.me/Stickers): `/newanimated` для
стикеров, `/newemojipack` для эмодзи, приложить файлы `.tgs`.

Три широких файла (`logo-wordmark-wave`, `logo-wordmark-wipe`,
`logo-wordmark-type`) в стикер-пак не идут — у них не квадратный
канвас. Это заставки для видео, сайта и шапок, а не стикеры.

## Как пересобрать или изменить

Ни один JSON не редактируется руками — всё генерируется кодом.

```bash
npm run generate-lottie        # пересобрать все 61 файл
node tools/lottie/validate.js  # схема + требования Telegram
```

| Файл | Отвечает за |
|---|---|
| `tools/lottie/lib.js` | примитивы Lottie: парсер SVG `path d` → кривые, фигуры, слои, ключи |
| `tools/lottie/motion.js` | язык движения: пружины, отскоки, дыхание, дрожание |
| `tools/lottie/icons.js` | азбука иконок: геометрия, оптический вес, обводка и блики |
| `tools/lottie/compose.js` | сборка стикера: вход, акценты, тень |
| `tools/lottie/build-*.js` | сами наборы: логотипы, реакции, эмодзи |

Поменять акцентный цвет всего пака — одна строка `BRAND.lime`
в `tools/lottie/lib.js`, дальше `npm run generate-lottie`.
