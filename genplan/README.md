# Генплан «БОР 495» — параметрическая модель для Rhino 7

Генератор собирает генплан по кадастровой границе участка и выдаёт:

* `BOR495_genplan_<вариант>.3dm` — модель для **Rhino 7** (метры, 10 слоёв);
* `BOR495_genplan_<вариант>.png` — план с подписями, сеткой и масштабом;
* `BOR495_genplan_<вариант>.txt` — ТЭП и протокол нормативных проверок.

Варианты: **A** — состав презентации + гостиница; **B** — то же плюс гостевые домики.

## Запуск

```bash
pip install rhino3dm shapely matplotlib
python3 genplan.py                           # реальный контур (site_real.txt), оба варианта
python3 genplan.py --site kpt.xml            # когда придёт XML КПТ/выписки ЕГРН
python3 genplan.py --placeholder             # условный прямоугольник
```

Участок по умолчанию — `site_real.txt`: 54 720 м² (5.47 га), периметр 948 м,
грани 290.2 / 230.4 / 180.6 / 247.7 м. Контур оцифрован со скриншотов ПКК и
Яндекс.Карт, масштаб откалиброван по площади; периметр и замер грани 289 м
сходятся в пределах 0.5 %. Для рабочей документации контур нужно заменить
на координаты из выписки ЕГРН.

`--site` принимает XML КПТ / выписки ЕГРН либо текстовый список координат
(`kpt.py` сам разворачивает порядок ЕГРН X=север/Y=восток в привычный CAD-овский).

## Слои модели

| Слой | Содержимое |
|---|---|
| 01_Граница_участка | кадастровый контур |
| 02_Линия_отступа | линия отступа `SETBACK` от границы |
| 03_Забор | ограждение h=2.2 м |
| 04_Проезды / 05_Парковка / 06_Дорожки | покрытия |
| 07_Здания_3D | объёмы (экструзии по высоте) |
| 08_Пятна_застройки / 09_Площадки | пятна и площадки |
| 10_Подписи | номера и названия |

## Экспликация

Экспликация на листе и в отчёте строится из того же перечня объектов, который
рисуется на плане, — расхождение между планом и экспликацией невозможно по
построению. Нумерация 1–13 сохранена из презентации, 14 — гостиница,
15 — падл-корт, 16 — гостевые домики (вариант 2).

## Что движок делает сам

* строит локальную систему координат участка (`u` вдоль длинной оси от въезда,
  `v` поперёк) — композиция переносится на любой контур без ручной перестановки;
* раскладывает фасадный ряд с противопожарными разрывами и считает, хватает ли фронта;
* разводит здания до нормативных разрывов (СП 4.13130: V–V 15 м, V–III 12 м, III–III 8 м);
* убирает застройку с проездов, а парковки — с пятен застройки;
* держит всё внутри линии отступа;
* считает ТЭП: застройка / покрытия / озеленение, машиноместа.

## Что нужно уточнить (пока стоят заглушки)

1. **Координаты из выписки ЕГРН** — чтобы заменить оцифрованный контур на точный
   и привязать модель к МСК-50.
2. **Габариты зданий** — в `config.py`, блок `PROGRAM_BASE` (сейчас ориентировочные).
3. `SETBACK` — фактический отступ по ПЗЗ, сейчас 3 м.
4. Степень огнестойкости бань и домиков (`fire`): от неё напрямую зависит,
   сколько объектов влезает на участок.
