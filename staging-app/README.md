# Нейро Стейджинг — MVP

Продуктовый прототип студии «Нейро Отличник»: **фото комнаты → та же комната с ремонтом**.
Сделан как Telegram Mini App на том же стеке и в той же фирменной палитре, что и игра
«Найди 5 отличий», но живёт отдельной папкой и с игрой никак не пересекается.

## Зачем это

Покадровый рендер — услуга: выручка линейна по людям, чек падает, клиент приходит
проектами. Стейджинг — продукт: тот же движок, но аудитория в сотни раз шире и
покупает регулярно. За рубежом это уже сформированный рынок (~$1,3 млрд в 2026-м),
в России промышленного сервиса нет.

## Одно действие — четыре сценария

Движок один: «фото → ремонт с сохранением геометрии». Меняется только упаковка выдачи:

| Кому | Что получает | Зачем платит |
|---|---|---|
| Риелтор | Кадр для объявления с подписью «визуализация» | Объявление перестаёт выглядеть «убитым» |
| Ремонтная компания | «Было/стало» в коммерческое предложение | Продаёт ремонт до начала работ |
| Дизайнер | Быстрый эскиз до договора | Закрывает сделку на первой встрече |
| Собственник | Примерка своей квартиры | Решает, во что вкладываться |

## Что уже работает

Полный сценарий кликается на реальном фото:

1. **Главная** — баланс кадров, загрузка фото с телефона, демо-пример.
2. **Настройка** — тип помещения, 6 стилей ремонта, режим выдачи
   («для объявления» с обязательной подписью / «для презентации» без неё).
3. **Обработка** — прогресс по этапам с фактами студии.
4. **Результат** — шторка «было/стало», скачивание, «Поделиться», «другой стиль».
5. **Тарифы** — три пакета с автоматическим пересчётом цены за кадр.
6. **История** — все сделанные кадры хранятся на устройстве.

Кадр списывается **только после успешной генерации** — за брак клиент не платит.

## Что имитируется

`src/pipeline.js`, режим `mock`: кадр обрабатывается прямо в телефоне (тонировка под
выбранный стиль + подпись) и помечается бейджем «ДЕМО-РЕЖИМ». Это нужно, чтобы вся
механика продукта щупалась на реальных фото и без единого рубля на GPU.

Ничего никуда не отправляется: фото не покидает устройство.

## Как запустить

```bash
npm run staging      # откроется на http://localhost:3000/staging-app/
```

Чтобы открыть в Telegram: залить папку на любой хостинг со статикой (как игру),
создать бота в BotFather и указать URL Mini App.

## Как включить настоящую генерацию

Меняется один файл — `src/config.js`:

```js
MODE: 'remote',
API_BASE: 'https://адрес-вашего-сервера',
```

Остальной код не меняется: контракт с бэкендом уже описан в `renderRemote()`
(`POST /api/jobs` → опрос `GET /api/jobs/:id` → готовый файл).

## Что нужно от владельца перед реальным запуском

Софт целиком делается без вашего участия. Не делается без вас вот это:

| Шаг | Время |
|---|---|
| Создать бота в BotFather | 5 минут |
| Оплатить GPU/API для генерации | 30 минут |
| Подключить ЮKassa/СБП (нужны ИП или ООО и счёт) | ~1 час + 1–3 дня проверки |
| Оплатить хостинг и домен | 20 минут |
| Уведомление в РКН об обработке персональных данных (152-ФЗ) | ~1 час |
| Дать 20–30 реальных фото квартир для отладки качества | 30 минут |
| Принять качество: «такой кадр отдам клиенту / не отдам» | 2–3 подхода по 30 минут |
| 20 разговоров с риелторами и ремонтниками | главная работа, только вы |

## Правовая рамка

Кадр в объявление уходит с несмываемой подписью «ВИЗУАЛИЗАЦИЯ · НЕ ФОТОГРАФИЯ».
Это не ограничение, а защита: площадки и закон о рекламе не любят выдачу
визуализации за фотографию, а честная маркировка снимает претензии заранее.

## Структура

```
staging-app/
  index.html          экраны
  src/config.js       тарифы, ссылки, режим работы  ← правится без программиста
  src/presets.js      стили и типы помещений        ← правится без программиста
  src/pipeline.js     генерация: заглушка и боевой режим
  src/store.js        баланс кадров и история (localStorage + IndexedDB)
  src/app.js          логика экранов
  src/style.css       оформление в палитре студии
```
