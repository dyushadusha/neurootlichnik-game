**Общаться простым языком, без жаргона.** Пользователь явно просил объяснять
происходящее понятно, не как программисту.

# Где живут скиллы (схема с 18.10.2026)

Чтобы скиллы работали во всех чатах (claude.ai, приложение на компьютере, Cowork, облачные
сессии с любым репозиторием), они ставятся как плагины в аккаунт claude.ai и должны быть
**включены** на claude.ai/customize/plugins (загруженный, но выключенный плагин нигде не работает):
- `neuro-otlichnik` — все скиллы студии одним плагином (всё из `.claude/skills/` этого репозитория
  + видео: Remotion, video-use, ffmpeg). Собирается вручную в zip и загружается через Upload plugin.
- `hyperframes` — официальный плагин HeyGen (видео), загружен zip-ом.
- `superpowers` — из каталога Claude (Discover), обновляется сам.
Статус: 18.10.2026 все пять плагинов (neuro-otlichnik, hyperframes, superpowers, Social Media Skills,
legalzoom) стоят в аккаунте; в обычном чате подтверждено — доступны 69 скиллов и 4 агента neuro-otlichnik.
Копии в `.claude/skills/` остаются, пока не подтверждено, что плагины из аккаунта появляются в
облачных сессиях (проверка: папка `~/.claude/plugins/synced/` в новой сессии не пустая);
после подтверждения копии можно убрать, чтобы скиллы не дублировались.
При добавлении нового скилла: положить в `.claude/skills/`, пересобрать zip `neuro-otlichnik`
и попросить владельца загрузить новую версию.

# Автоматическое применение скиллов

Пользователь хочет, чтобы установленные скиллы подключались сами по контексту
запроса, без необходимости называть их явно или помнить, что вообще установлено.
Поэтому: при любой задаче в категориях ниже — активно подбирай нужный скилл сам,
не жди, что пользователь его назовёт.

## Установленные скиллы (.claude/skills/)

**Дизайн и графика (для соцсетей, сайта, презентаций):**
- `banner-design` — баннеры для соцсетей, рекламы, hero-баннеры сайта
- `brand` — брендбук, tone of voice, единообразие визуала
- `design` — общий дизайн: логотипы, иконки, слайды, соцфото
- `design-system` — дизайн-токены, компоненты, системный подход к дизайну
- `slides` — презентации (HTML-слайды с графиками)
- `ui-styling` — UI-компоненты, Tailwind, доступность
- `ui-ux-pro-max` — большая база знаний по UI/UX: стили, шрифты, цвета, иконки, паттерны

**Продуктивность / мышление:**
- `llm-council` — прогнать решение через 5 «советников» с разными точками зрения
  (триггеры: «council this», «прогони через совет», важные развилки/решения)
- `grill-me` / `grilling` — «допрос» по плану/идее, чтобы довести до чёткого решения
- `task-observer` — сам следит за сессией и предлагает новые скиллы/улучшения

**Instagram** (`ig-*`, 13 скиллов, установлено 06.10.2026 из github.com/Jakeschincariol/instagram-agent-skill,
коммит `d03c56b`, лицензия MIT; работают без ключей и без подключения к Instagram — только пишут тексты):
- `ig-reel` — сценарий рилса: 3 хука из 26 формул с оценкой, текст на экране, раскадровка по секундам
- `ig-viral` — что сейчас «залетает» в нише (по ссылкам/данным, которые дал пользователь)
- `ig-caption` — подпись к посту с проверкой обрезки «ещё»; `ig-carousel` — карусель; `ig-story` — сторис
- `ig-plan` — контент-план на неделю; `ig-profile` — оценка и доработка профиля; `ig-audit` — аудит аккаунта
- `ig-comment`, `ig-reply`, `ig-dm` — комментарии, ответы, сообщения в директ
- `ig-repurpose` — переделать материал в формат Instagram; `ig-human` — убрать «ИИ-шность» из текста
Писать на русском, в голосе студии; визуал — по дизайн-системе бренда.

**Видео и монтаж** — только в плагинах аккаунта, не лежат в этом репозитории. Источники —
`.claude/skills/VIDEO-SKILLS-SOURCES.md`. Плагин `hyperframes` (скиллы вызываются как
`hyperframes:<имя>`) и плагин `neuro-otlichnik` (Remotion, video-use, ffmpeg):
- `video-use` — монтаж готовых съёмок разговором: нарезка по речи, удаление пауз/оговорок,
  цветокор, субтитры, наложение анимаций. ⚠️ Расшифровка речи требует ключа ElevenLabs
  (`ELEVENLABS_API_KEY`) — без него остальное работает, но резать по словам не сможет
- `hyperframes` — ГЛАВНЫЙ вход для «сделай видео/анимацию/ролик»: сам выбирает нужный сценарий ниже
  - `motion-graphics` — короткие анимации до 30 сек: кинетическая типографика, логотип-заставка,
    цифры, плашки, анимированная карта
  - `general-video` — длинные/многосценные ролики, шоурилы, монтаж из футажей
  - `music-to-video` — ролик под музыку с нарезкой в такт (слайдшоу рендеров, промо)
  - `embedded-captions` — субтитры поверх видео с говорящим (35 стилей, работает локально)
  - `talking-head-recut` — графические плашки/заголовки/цифры поверх интервью или «говорящей головы»
  - `faceless-explainer` — видео-объяснение из текста без съёмки (графика, схемы, типографика)
  - служебные: `hyperframes-core`, `hyperframes-animation`, `hyperframes-creative`, `hyperframes-cli`,
    `hyperframes-audio` (сведение звука), `hyperframes-keyframes` (зумы, движения камеры),
    `hyperframes-registry` (~400 готовых эффектов), `hyperframes-studio`, `media-use` (музыка, звуки, озвучка)
- `remotion-best-practices` — официальные скиллы Remotion (для подпроекта `social-video/`):
  `remotion-create`, `remotion-captions`, `remotion-render`, `remotion-studio`, `remotion-markup`,
  `remotion-multimedia`, `remotion-maps`, `remotion-docs`, `remotion-upgrade`, `remotion-interactivity`
- `ffmpeg` — шпаргалка по конвертации, сжатию, обрезке, смене формата 16:9 → 9:16, извлечению звука

Выбор движка: для рилсов с нуля — HyperFrames (по умолчанию); если правим `social-video/` — Remotion;
если есть сырое видео с речью — `video-use`. Всегда соблюдать дизайн-систему бренда
(цвета только `#2A2A2A` / `#DBFC3B` / `#FFFFFF`, шрифты Kica / Inter Tight / Pershotravneva55).

**Код (для игры и других программ)** — `ponytail` (установлено 18.10.2026 из github.com/DietrichGebert/ponytail,
коммит `09c434a`, MIT): режим «ленивого опытного программиста» — самое короткое рабочее решение,
без лишнего кода, ответ понятным языком. Плюс `ponytail-review` (проверка изменений),
`ponytail-audit` (аудит всего проекта), `ponytail-debt`, `ponytail-gain`, `ponytail-help`.
Применять при любой работе с кодом игры.

**Agent Skills — инженерный процесс от идеи до запуска** (установлено 18.10.2026 из
github.com/addyosmani/agent-skills, коммит `aeac41d`, MIT; 25 скиллов в `.claude/skills/`,

test-engineer, web-performance-auditor). Главное для владельца:

- `debugging-and-error-recovery` — разобраться, почему что-то сломалось
- `security-and-hardening`, `performance-optimization`, `shipping-and-launch` — безопасность, скорость, запуск
- `frontend-ui-engineering`, `browser-testing-with-devtools` — интерфейс игры и проверка в браузере
- `using-agent-skills` — карта всего набора, если неясно, что выбрать
Для кода сочетать с `ponytail` (минимум кода).

**Данные и код:**

# Правила установки нового

Не устанавливать что-либо (skills/MCP/пакеты) без явной просьбы пользователя.
Перед установкой непроверенных/неоднозначных инструментов — коротко проверять
источник (репозиторий, автора, лицензию) и не запускать код с неясным происхождением
без объяснения рисков пользователю.
