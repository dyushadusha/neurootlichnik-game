# О владельце и бизнесе

Пользователь — основатель студии архитектурной нейровизуализации «Нейро Отличник».
Не программист, работает с Claude Code как с ассистентом, а не как разработчик.

Основной фокус:
- Визуализации с помощью ИИ (архитектурная нейровизуализация)
- Продвижение в соцсетях
- Графика для презентаций, сайта и компании в целом (баннеры, слайды, брендинг)
- Видео-контент для соцсетей

Этот репозиторий (`neurootlichnik-game`) — Telegram Mini App игра «Найди 5 отличий»
для этой же студии, но пользователь также использует эту сессию для более широких
бизнес-задач (дизайн, контент, соцсети), не только для кода игры.

**Общаться простым языком, без жаргона.** Пользователь явно просил объяснять
происходящее понятно, не как программисту.

# Автоматическое применение скиллов

Пользователь хочет, чтобы установленные скиллы подключались сами по контексту
запроса, без необходимости называть их явно или помнить, что вообще установлено.
Поэтому: при любой задаче в категориях ниже — активно подбирай нужный скилл сам,
не жди, что пользователь его назовёт.

## Установленные скиллы (.claude/skills/)

**Дизайн и графика (для соцсетей, сайта, презентаций):**
- `banner-design` — баннеры для соцсетей, рекламы, hero-баннеры сайта
- `brand` — брендбук, tone of voice, единообразие визуала
- `design` — общий дизайн: логотипы, иконки, слайды, соцфото
- `design-system` — дизайн-токены, компоненты, системный подход к дизайну
- `slides` — презентации (HTML-слайды с графиками)
- `ui-styling` — UI-компоненты, Tailwind, доступность
- `ui-ux-pro-max` — большая база знаний по UI/UX: стили, шрифты, цвета, иконки, паттерны

**Продуктивность / мышление:**
- `llm-council` — прогнать решение через 5 «советников» с разными точками зрения
  (триггеры: «council this», «прогони через совет», важные развилки/решения)
- `grill-me` / `grilling` — «допрос» по плану/идее, чтобы довести до чёткого решения
- `task-observer` — сам следит за сессией и предлагает новые скиллы/улучшения

**Данные и код:**
- `graphify` — построение графа знаний по коду/докам/картинкам
  ⚠️ ТОЛЬКО по явной команде `/graphify` — не включать автоматически (дорого по токенам)

## Установленные MCP-серверы (.mcp.json — требуют подтверждения при первом запуске сессии)
- `playwright`, `chrome-devtools` — реальный браузер: открыть сайт, проверить, сделать скриншот
- `glif` — AI-генеративные воркфлоу с glif.app (требует входа через браузер при первом использовании)

## Установлено глобально (не в этом репозитории — не переживёт новую сессию/контейнер)
- `agent-reach` — чтение/поиск в интернете и соцсетях (Twitter, YouTube, GitHub, RSS, веб-страницы;
  доп. каналы вроде Reddit/Instagram/Facebook можно доустановить по запросу — требуют логина
  через cookie конкретной соцсети)
- `claude-mem` — плагин, запоминает контекст между чатами (Claude Code plugin, scope: user)

## Отдельный подпроект
- `social-video/` — Remotion-проект для создания видео-роликов для соцсетей кодом
  (не Claude-скилл, отдельный React/Remotion проект со своим package.json)

# Правила установки нового

Не устанавливать что-либо (skills/MCP/пакеты) без явной просьбы пользователя.
Перед установкой непроверенных/неоднозначных инструментов — коротко проверять
источник (репозиторий, автора, лицензию) и не запускать код с неясным происхождением
без объяснения рисков пользователю.
